# ADR-002. На macOS офлайн-vendor лежит РЯДОМ с `.app`, а не внутри

**Статус:** принято · **Дата:** 2026-08 · **Область:** сборка macOS, доставка

## Контекст

Офлайн-издание несёт ~2,7 ГБ vendor: питоновские колёса, архивы приложений,
браузеры Playwright. Естественное место для них — внутрь бандла
`Hamidun Setup.app/Contents/Resources`, как делает `extraResources` у
electron-builder на Windows.

На macOS так нельзя. Нотаризация Apple проверяет **каждый** Mach-O внутри бандла,
а внутри `.whl` лежат неподписанные `.so`. Нотаризация такой бандл отклоняет.
Обойти это подписанием чужих колёс невозможно: они пересобираются, их содержимое
не наше, и подписывать чужой бинарь своим Developer ID — не то, что стоит делать.

## Решение

`.app` собирается **чистым** — его подписывает Developer ID и нотаризует
electron-builder, после чего нотаризация стейплится в бандл. Финальный dmg
собирается отдельно, `hdiutil` из стейджинг-каталога, где рядом лежат:

```
Hamidun Setup.app     ← нотаризован и застейплен
vendor/               ← 2,7 ГБ, вне бандла
ПРОЧТИ ЕСЛИ ПИШЕТ ПОВРЕЖДЕНО.txt
Applications          ← симлинк
```

Сам dmg подписывается Developer ID, но **не нотаризуется**: vendor внутри снова
завалил бы проверку, а приложение и так застейплено.

## Чем платим

Дорого и заметно: **приложение нужно запускать прямо из окна dmg.**

Перетащил в «Программы» — vendor остался на образе, приложение его не находит и
показывает стоп-экран. Это противоречит мышечной памяти каждого пользователя
macOS, поэтому:

* на образе лежит текстовая инструкция, и её копирование в dmg сделано
  **fail-closed** — раньше оно шло с `2>/dev/null || true`, и любая осечка с
  кириллическим именем молча выпускала образ без единственного файла, который
  читает застрявший человек;
* установщик сам предупреждает, если его запустили из `/Applications`;
* пять документов сведены к одной формулировке — до этого они давали три разные.

Старый совет «перетащи в Программы, потом `xattr -cr "/Applications/…"`»
**вреден**: он ведёт ровно к тому стоп-экрану, от которого человек пришёл.

## Что рассматривалось и отвергнуто

* **Vendor внутрь бандла** — нотаризация отклоняет, см. контекст.
* **Не нотаризовать вовсе** — Gatekeeper показывает «повреждено», и человек без
  терминала остаётся с кирпичом.
* **Скачивать vendor после установки** — это и есть лёгкое издание; офлайн-издание
  существует именно для отсутствия сети.
