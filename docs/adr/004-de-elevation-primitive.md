# ADR-004. Де-элевация — единый примитив, а не приём на местах

**Статус:** принято · **Дата:** 2026-07 · **Область:** безопасность, Windows

## Контекст

Часть установки требует прав администратора: системные установщики, запись в
`Program Files`, реестр. Но сразу после этого установщику нужно запускать вещи,
лежащие **в папке пользователя** — редактор из `%LOCALAPPDATA%`, расширения,
проверочные команды.

Запустить их с унаследованными правами администратора значит отдать эти права
любому, кто может писать в пользовательский каталог. А писать туда может кто
угодно, кто уже выполняется от имени этого пользователя, — то есть привилегии
повышаются в один шаг, и виноват в этом установщик.

Соблазн простой: «здесь мы точно знаем, что запускаем, и один раз можно».

## Решение

Нельзя ни разу. Есть **один** примитив `Invoke-HmDeElevated`
(`scripts/windows/_deelev.ps1`), и всё, что живёт в пользовательском пространстве,
идёт через него. На него стоит отдельный CI-гейт и отдельные тесты.

Примитив укреплён по конкретным атакам, а не «на всякий случай»:

* **никаких control-файлов в общем `%TEMP%`** — тело обёртки передаётся
  `-EncodedCommand` (base64 из UTF-16LE), собранным родителем;
* **приватный staging-каталог** (`ProgramData` + `icacls` + проверка), а не
  доступный на запись всем;
* **env-литералы раньше cmdlet**, абсолютный путь к `whoami`, аттестация
  результата — чтобы подмена окружения не подменила смысл команды;
* **fail-closed**: не подтвердилось понижение прав — не запускаем вовсе.

Компонентов, зовущих де-элевацию, **пять**: мост, claude, расширение, handy,
vscode. Остальные закрыты иначе — `Test-HmTrustedSigner` проверяет подпись, и
де-элевация им не нужна. Эта цифра ошибалась в модели угроз (там стояло девять) и
выправлена 2026-08-29: неверное число здесь дороже отсутствия числа, потому что по
нему ищут покрытие.

## Чем платим

* **Сложность.** Понизить права в Windows нетривиально; примитив занимает заметный
  кусок кода и требует тестов на PowerShell 5.1, которые медленные.
* **Ограничение на новые компоненты.** Захотел запустить что-то из пользовательской
  папки — обязан идти через примитив, даже если «тут точно безопасно».
* **Отладка тяжелее**: ошибка внутри обёртки видна не сразу.

Цена принята: альтернатива — привилегированное исполнение чужого кода, а это не
компромисс, а дефект.
