# ADR-006. Число либо измерено, либо его нет

**Статус:** принято · **Дата:** 2026-08 · **Область:** UI, сборка

## Контекст

Размер компонента задавался рукописной строкой в `components.json`: `sizeHint`
вида «~110 МБ». Строку никто не пересчитывал при обновлении vendor, и она уехала:

| Компонент | Обещали | На самом деле |
|---|---|---|
| VS Code | ~110 МБ | 221,6 МиБ |
| Расширение | ~10 МБ | 85,6 МиБ |
| Claude CLI | ~50 МБ | 1036,8 МиБ |

Цифра видна в двух местах — бейджем на карточке и в попапе «что скачается на мой
ПК», — то есть ровно там, где снимается страх «а не вирус ли это». И вот здесь
заниженная вдвое сумма работает **против** себя: человек качает файл на 1,9 ГБ,
видит рядом «примерно 400 МБ» и делает единственный доступный ему вывод — его
обманывают. Честный большой размер такого вывода не порождает.

## Решение

Числа не пишут — их считают. `tools/sync-sizes.js` меряет фактические байты
артефактов в `vendor` и записывает `sizeBytes[<платформа>]`. Слова остаются за
человеком (`sizeNote`), цифры — за скриптом.

Не удалось измерить — **числа нет**. На карточке прочерк и честная пометка вроде
«+ Python и библиотеки докачиваются из интернета». Компонент без вшитого артефакта
не получает числа вовсе.

`npm run sizes:check` — гейт расхождения без перезаписи: разошлось — `exit 1`.

## Что это число НЕ означает

Важно, потому что путают: `sizeBytes` — вес **дистрибутива внутри установщика**,
сколько байт компонент приносит из самого exe. Это не след на диске после
распаковки (установленный Git кратно больше `git-setup.exe`) и не трафик. Размер
докачки в лёгком издании живёт отдельно — в `remote-components.json`, и второй
копии этого факта в `components.json` нет сознательно: две копии одного числа
расходятся.

## Чем платим

* **Числа появляются только там, где развёрнут vendor.** На чистой машине и в CI
  сверять физически не с чем.
* **Платформенность.** Один компонент едет разными артефактами (vscode: 221,6 МиБ
  setup.exe против 520,1 МиБ zip), поэтому поле платформенное, и mac-числа берутся
  только на маке.

## Гоча, купленная 2026-08-29

Флаг `--force` позволяет посчитать чужую платформу. Запуск
`--platform darwin --force` на Windows переписал **три** числа виндовыми байтами
(claude 135→103 МиБ, nomad 165→110, mascot 202→279). Все правдоподобны, ни одно не
верно, код возврата — ноль.

Причина: у `claude` и `nomad` пути в vendor **одинаковые** (`npm-cache/`,
`nomad-src/`), содержимое туда кладёт `fetch-vendor` — своё для каждой ОС.
Поэтому совпадение путей здесь признак **опасности**, а не безопасности, и первая
редакция защиты, сравнивавшая пути, пропустила ровно те три числа, ради которых
заводилась.

Теперь запрет покомпонентный: в чужую платформу пишутся только артефакты из
`PLATFORM_INDEPENDENT`. Там ровно один — курс: закоммиченный в репозиторий zip,
физически один и тот же на всех ОС. Переносимость — свойство артефакта, а не пути,
и объявить её можно только руками.
