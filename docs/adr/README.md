# Записи об архитектурных решениях (ADR)

Здесь лежат решения, которые дорого пересматривать и ещё дороже пересматривать
случайно — потому что причина забылась, а последствие осталось.

Каждая запись отвечает на три вопроса: **что было выбрано**, **против чего** и
**чем за это платим**. Раздел «Чем платим» обязателен: решение без названной цены
выглядит бесплатным, и первый же человек, которому оно мешает, отменит его.

Формат намеренно короткий. ADR читают в момент «а почему тут так?», и лонгрид в
этот момент не читают вовсе.

## Когда заводить новую запись

Не на каждое решение, а когда верно хотя бы одно:

* решение дорого откатывать (формат публикации, схема подписи, модель прав);
* решение выглядит странно, и следующий человек захочет его «исправить»;
* решение куплено инцидентом — тогда запись хранит цену, а не только вывод.
